# pipeline-analytics

Self-hosted pipeline analytics for GitHub Actions and Forgejo Actions — duration
trends, failure rates, flaky-step detection, and health status for a solo
developer's own repos.

No code yet. The full design lives in the OpenSpec change at
[`openspec/changes/add-pipeline-dashboard`](openspec/changes/add-pipeline-dashboard/proposal.md).
